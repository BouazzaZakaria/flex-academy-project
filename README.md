# Flex Academy

Flex Academy is a modern, high-converting landing page built for fitness coaches and personal trainers who want to scale their businesses sustainably. The platform provides proven frameworks for client acquisition, program delivery, and operational scaling, strictly avoiding "guru" tactics in favor of tested systems that perform in today's market.

Built using React, Vite, TypeScript, Tailwind CSS, and Framer Motion, this project features a highly responsive, single-page architecture targeting premium aesthetics and fluid interactions. 

### Key Features
- **Modern Tech Stack**: Lightning-fast builds with Vite, robust typing with TypeScript, and utility-first styling with Tailwind CSS.
- **Premium Design System**: Fluid typography, carefully curated color palettes (Forest Green, Cream, Accent), and glassmorphism elements.
- **Interactive UI/UX**: Uses Framer Motion for scroll-reveals, smooth transitions, count-up animations, and mobile-first bottom sheet modals.
- **Dynamic Flows**: Features multi-step wizards for strategy call bookings and webinar registrations, including dynamic `.ics` calendar generation on the client side.
- **Accessible & Performant**: Built with semantic HTML, comprehensive focus states, and optimized for Lighthouse performance metrics.
